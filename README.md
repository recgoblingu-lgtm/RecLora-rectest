# RecLora — rebranded rectest mirror

This repository is a static, route-preserving copy of the existing `rectest` repository, rebranded to RecLora. It contains the source repository's locally mirrored HTML routes and assets, with site-level branding changed to RecLora, Studio Lora, and the Purple & Gold theme.

## What changed

- Kept the existing static page and asset structure from `rectest`.
- Replaced DreamRec / Rec Room site-level branding with RecLora.
- Replaced Studio 87 site-level references with Studio Lora.
- Applied Purple & Gold theme tokens through `reclora-theme.css`.
- Added the supplied RecLora logo as `logo.png`, `favicon.png`, and the supporting logo variant.
- Preserved the original route/page content structure and local assets.

This is a static site: serve the repository root with any static file server or deploy it to GitHub Pages.
